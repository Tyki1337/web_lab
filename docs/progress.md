# Отчет по Лабораторной работе №1

## Описание результатов ЛР 1
В рамках лабораторной работы создано одностраничное веб-приложение **«Expense Tracker»** на React (с использованием TypeScript). 

Приложение позволяет:
1. Вести учет доходов и расходов с поддержкой динамического добавления и удаления транзакций.
2. Автоматически рассчитывать и обновлять финансовую сводку (общий баланс, сумму доходов и сумму расходов).
3. Отображать стилизованный список операций и удобную форму ввода.

---

## Шаги проверки (3–6)

### Шаг 3: Добавление новой записи
- **Описание:** Пользователь заполняет текстовое поле с названием операции, числовое поле с суммой и выбирает тип (`income` / `expense`). При клике на кнопку «Добавить» срабатывает функция `handleAddTransaction`.
- **Проверка валидации:** Если название пустое или сумма не является положительным числом, выводится сообщение с предупреждением (`alert`).
- **Результат:** При корректном вводе создается новый объект транзакции с уникальным ID (`Date.now()`) и добавляется в начало списка `transactions`. Поля формы автоматически очищаются.

---

### Шаг 4: Удаление записи
- **Описание:** Возле каждой транзакции в списке отображается кнопка «✕» с вызовом обработчика `handleDelete(id)`.
- **Результат:** Элемент с указанным `id` отфильтровывается из массива `transactions`, список мгновенно перерисовывается, а финансовая сводка пересчитывается.

---

### Шаг 5: Расчет финансовой сводки
- **Описание:** Сводка рассчитывается динамически на основе текущего состояния `transactions`:
  - `totalIncome` — сумма всех транзакций типа `income` (используются `filter` и `reduce`).
  - `totalExpense` — сумма всех транзакций типа `expense`.
  - `balance` — разница между `totalIncome` и `totalExpense`.
- **Результат:** Карточка «Баланс» меняет стили (зеленый/красный цвет текста) в зависимости от того, положительный баланс или отрицательный (`balance >= 0`).

---

### Шаг 6: Проверка отображения и Edge Cases
- **Пустое состояние (Empty State):** При удалении всех записей из списка показывается текстовое уведомление: *«Записи о доходах и расходах пока отсутствуют.»*
- **Стилизация:** Применены CSS-классы для адаптивной верстки, цветовой индикации типов операций (зеленый для доходов, красный для расходов) и оформления интерактивных элементов.

# Expense Tracker — Приложение для учета личных финансов

Приложение для контроля доходов, расходов и ведения бюджета.

## Информация о проекте
* **Тема:** Веб-приложение для учета личных финансов («Expense Tracker»)
* **Автор:** Беляев Сергей Александрович
* **Группа:** ФТ24ДР62ИС

---

## Основной сценарий использования
1. Просмотр сводки по финансовому состоянию (текущий баланс, общие суммы доходов и расходов).
2. Просмотр истории финансовых операций.
3. Добавление новых записей о доходах и расходах с проверкой корректности вводимых данных.
4. Удаление существующих записей из истории операций.

---

## Технологический стек
* **Frontend:** React, TypeScript, HTML5, CSS3
* **Сборка:** Vite / npm
* **Версия Node.js:** 18.x или выше (рекомендуется LTS Версия 20.x)

---

## Запуск проекта

### Запуск из корня скачанного проекта:
```bash
cd frontend
npm ci
npm run dev
```

После выполнения команд приложение будет доступно в браузере по адресу, указанному в консоли (обычно `http://localhost:5173`).

## Проверка сборки

Для проверки продакшен-сборки остановите режим разработки (`Ctrl + C`) и выполните в папке `frontend`:

---

## Что работает сейчас (ЛР 1)
* Отображение текущего баланса, общих доходов и расходов с цветовой индикацией.
* Локальное состояние транзакций (добавление новых операций через клиентскую форму).
* Валидация полей формы перед добавлением (проверка названия и позитивности суммы).
* Динамический пересчет финансовых показателей при добавлении и удалении операций.
* Отображение пустого состояния (`empty state`), если список операций пуст.
